В переменных мы не можем хранить:
1. Комментарии
2. (if, else)
3. необъявленные переменные
4. Пустой код



Виды областей:
1. Глобальная -- доступная везде
2. Функциональная -- только внутри функции, где она объявлена
3. Блочная {}



Этапы создания объявлений:
1. Объявление -- сообщаем Js, что переменная существует
2. Инициализация -- присваиваем переменной значение при создании
3. Присваивание -- меняем значение после объявления



Правила именования переменных:
1. a-z, A-z
2. _
3. $
4. camelCase
5. UPPER_CASE - ( исключительно для констант значения, которых никогда не меняется - логические/математические)



Практики:
1. использовать только let, const
2. Даем переменной понятное и конкретное именования
3. camelCase - стандарт

let const - блочная видимость
var - глобальная область видимости / функциональная
